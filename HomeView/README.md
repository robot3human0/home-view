# HomeView — Mac ilovasi

To‘liq qo‘llanma (fasllar, ofis tarmog‘i, Mac mini'ga server o‘rnatish) — yuqoridagi papkadagi `README.md` da.

Tez yig‘ish:

```bash
./make_dmg.sh        # natija: dist/HomeView-<versiya>.dmg
```

Xcode'da ochish: `open Package.swift` → HomeView → My Mac → ▶ Run.
Yonidagi `../HomeViewProtocol` papkasi bo‘lishi shart — ilova u bilan birga yig‘iladi.

Boshqaruv qisqacha:
- ⌃⌥G — o‘yin rejimi (Esc — chiqish).
- ⌥ + g‘ildirak — odamcha, yasalgan narsa yoki mashina ustida o‘lchamni o‘zgartirish.
- ⌘, — sozlamalar oynasi (fasl, o‘lchamlar, brigada, ofis).
