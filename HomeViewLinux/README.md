# HomeView для Linux

Linux-клиент [HomeView](../README.md) — сезонные осадки поверх всех окон и человечки коллег
из офисной сети. Подключается к **тому же серверу на Mac mini**, что и Mac-версия: вы видите
маководов, они видят вас.

> Статус: прототип (MVP) на Python + PySide6. Работает только в сессии **X11**.

## Что умеет

| | |
|---|---|
| 🍂 Осадки | Снег / лепестки урюка / тополиный пух / листья — по сезону (или вручную), на всех мониторах |
| 👥 Коллеги | Человечки с именами гуляют внизу основного монитора; «Отошёл» — сидит, «Занят» — полупрозрачный |
| 🖱 Клик по человечку | Помахать, кинуть снежок (листок, водяной шарик…), написать, позвать на чай, убрать с экрана |
| 📥 Входящее | Коллега машет / кидает снежок (прилипает к экрану) / пишет / зовёт на чай — карточки справа вверху |
| 🔔 Статус | Активен / Отошёл / Занят / Невидимка; «Отошёл» включается сам через 5 минут простоя |
| 🎮 Игры | **Пока нет.** Приглашения приходят, их можно вежливо отклонить |

Клики по пустому месту проходят в окна под оверлеем — он не мешает работать.

## Установка

```bash
sudo apt install libxcb-cursor0        # нужно Qt ≥ 6.5 для X11
git clone git@github.com:robot3human0/home-view.git
cd home-view && git switch linux-client
./HomeViewLinux/run.sh                 # первый запуск сам создаст .venv и поставит PySide6, zeroconf
```

При первом запуске откроются настройки: имя, команда, человечек. Значок появится в трее
(в Ubuntu — через расширение AppIndicator, оно включено по умолчанию).

Сервер ищется автоматически (mDNS). Если не находится — впишите адрес Mac mini в
настройках → «Адрес сервера» (например `192.168.1.20` или `build-mini.local`).

**Видеокарта** (Настройки → «Чем рисовать»): по умолчанию дискретная, если её нет — встроенная.
Рисование на видеокарте занимает ≈10% одного ядра; режим «Процессор» — ≈60% и нагружает композитор,
поэтому при его включении HomeView предупреждает. Смена режима — с перезапуском клиента.

**Размер** человечков (по умолчанию 2×) и надписей (2,5×) — ползунками в настройках.

**Сессия:** только X11 («Ubuntu on Xorg» на экране входа). Под Wayland окно поверх всех и
пропускание кликов не работают — GNOME не даёт приложениям такой возможности.

## Как устроено

| Файл | Что делает |
|---|---|
| `homeview/protocol.py` | JSON-протокол, совместимый со Swift `Codable` (`HomeViewProtocol/Protocol.swift`, версия 4) |
| `homeview/net.py` | WebSocket + mDNS, переподключение 2→4→…30 с |
| `homeview/office.py` | Коллеги, статусы, обработка сообщений сервера, действия |
| `homeview/overlay.py` | Прозрачное override-redirect окно на каждый монитор (OpenGL или программное) |
| `homeview/gpu.py` | Выбор видеокарты: дискретная / встроенная / процессор, с пробным запуском |
| `homeview/gl_particles.py` | Осадки целиком в шейдере: одна команда рисования на слой |
| `homeview/x11.py` | XShape input region (клики только по человечкам), время простоя (XScreenSaver) |
| `homeview/world.py` | Мир монитора: осадки, человечки, эффекты |
| `homeview/particles.py` | Частицы для программного режима (спрайты заранее повёрнуты в 24 угла) |
| `homeview/avatar.py` | Человечек из PNG-частей, анимации как в `PeerAvatar.swift` |
| `homeview/art.py` | Загрузка `HomeView/Art/*.png`, перекраска «серый × цвет» |
| `homeview/toasts.py`, `tray.py`, `settings_window.py` | Карточки, трей, окно настроек |

Картинки берутся из `../HomeView/Art` (не копируются) — при обновлении от iOS-команды
подтянутся сами.

## Разработка и проверка без Mac mini

```bash
cd HomeViewLinux
.venv/bin/python tools/mock_server.py --bots 4 --advertise   # мок-сервер с ботами-коллегами
./run.sh --debug                                              # клиент (найдёт мок через mDNS)
.venv/bin/python -m unittest discover -s tests               # тесты протокола
```

Мок-сервер **строго проверяет формат** каждого сообщения клиента (как его ждёт Swift) и пишет
`ОШИБКА ФОРМАТА`, если что-то не так. Боты сами машут, кидаются, пишут, зовут на чай и в игры,
а на ваши действия отвечают.

Чтобы не трогать свои настройки при тестах: `XDG_CONFIG_HOME=/tmp/hv-test ./run.sh`.

### Проверка совместимости с настоящим Swift-протоколом

```bash
./HomeViewLinux/tools/swift_check/run.sh
```

Собирает `HomeViewProtocol` iOS-команды в Docker (`swift:6.0-noble`, ~1 ГБ при первом запуске) и
прогоняет все сообщения клиента через их `JSONDecoder`, а сообщения сервера от их `JSONEncoder` —
через наш декодер. Запускать после каждого нового архива HomeView от iOS-команды. Код возврата
не 0 — что-то разошлось. В рабочую копию ничего не пишется.

Настройки хранятся в `~/.config/HomeView/HomeViewLinux.conf`, автозапуск —
`~/.config/autostart/homeview-linux.desktop`.
